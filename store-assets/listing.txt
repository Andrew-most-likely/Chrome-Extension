--- LONG DESCRIPTION ---
Phishing Detector protects you from phishing sites, malware, payment fraud, and credential-harvesting forms in real time - before any harm is done.

WHAT IT BLOCKS

Phishing and Malware
Every site you visit is checked against Google Safe Browsing, one of the world's largest threat databases covering malware, phishing, unwanted software, and harmful applications.

Payment Redirect Fraud
Scripts that silently redirect you to payment platforms (PayPal, Stripe, Venmo, Coinbase, and more) are intercepted before the navigation happens. This is a common technique used in financial phishing attacks.

Suspicious URL Patterns
The extension flags dangerous URL structures before DNS even resolves, including:
- Bare IP addresses used instead of domain names
- Number-substitution lookalikes (paypa1.com, amaz0n.net, g00gle.com)
- IDN homograph attacks using look-alike Unicode characters (xn-- punycode domains)
- High-risk free domains (.tk, .ml, .ga, .cf, .gq)
- Brand names buried in subdomains of unrelated domains (paypal.attacker.net)
- Fake TLDs in hostnames (secure-login.com.attacker.net)
- The @ symbol URL trick (paypal.com@evil.com loads evil.com)

Credential-Harvesting Forms
Login forms that submit your password to a different website are detected and blocked. Legitimate sites always submit credentials to their own domain.

HOW IT WORKS

When a threat is detected you are redirected to a clear warning page that explains exactly why the site was flagged and what type of threat was found. You can go back to safety or choose to proceed - bypasses are session-only and automatically expire after 24 hours.

FEATURES

- Google Safe Browsing API v4 integration via secure proxy
- URL heuristic analysis (runs before the page loads - no waiting)
- Payment redirect interception via JavaScript Location API hooks
- Cross-origin form action scanning at page idle
- 24-hour auto-expiring session bypass list
- Permanent domain whitelist for sites you trust
- Full block history with threat type labels and timestamps
- Threat tally in the popup (Total, Phishing, Malware, Payment Redirect)
- Manage bypassed and whitelisted domains directly from the popup

PRIVACY

This extension does not collect, store, or share your browsing history. URL checks are sent to our secure proxy which forwards them to Google Safe Browsing - no URLs are logged. All block history stays on your device in local browser storage only. See the privacy policy for full details.


====================================================
PERMISSION JUSTIFICATIONS
(required by Chrome Web Store review)
====================================================

webNavigation
Used to listen for page navigations so URLs can be checked against Safe Browsing and URL heuristics before the page fully loads.

tabs
Used to redirect the active tab to the warning page when a threat is detected, and to navigate back to the new tab page when the user clicks "Go back to safety."

storage
Used to persist the block history, threat tally, and user whitelist (chrome.storage.local) and the session bypass list (chrome.storage.session). No data leaves the device.

scripting
Used to inject the payment redirect interceptor and form scanner content scripts into pages. These cannot be declared statically for all sites in all circumstances without this permission.

Host permission - https://*/*  and  http://*/*
Required to run content scripts on all websites to detect payment redirects and credential-harvesting forms, and to allow the background service worker to call our Safe Browsing proxy for any URL the user navigates to.
