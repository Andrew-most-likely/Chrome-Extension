Capabilities

Everything you need to stay safe

Google Safe Browsing

Every URL is checked against Google's database of suspected phishing, malware, and social engineering sites. Advisory provided by Google Safe Browsing.

Payment Redirect Detection

Inline scripts that may silently redirect you to PayPal, Stripe, crypto platforms, or other payment services are detected and flagged as potentially malicious.

Instant Warning Page

When a site is suspected to be dangerous, you see a warning page explaining why it was flagged - before anything renders.

Process

How it works

1

You navigate to a site

The extension intercepts every top-level page navigation automatically.

2

URL is checked

The URL is submitted to the Google Safe Browsing API and checked for known threats.

3

Scripts are scanned

Inline JavaScript is analysed on-device for redirect patterns targeting payment services.

4

You're warned or protected

If a threat is found, you see a blocking warning page with the full reason before anything loads.
