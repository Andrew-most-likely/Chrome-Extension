1. Acceptance of Terms

2. Description of Service

Vanta Security is a free browser extension that helps protect users from phishing websites, malware, and malicious payment redirects by:

  • Checking URLs against the Google Safe Browsing API
  • Scanning inline scripts for suspicious payment redirect patterns
  • Displaying warning pages when threats are detected

3. No Guarantee of Protection

Important: The Extension is a security aid, not an absolute guarantee. New phishing sites are created constantly. No security tool can catch 100% of threats.

The Extension relies on Google's Safe Browsing database, which may not include newly created phishing sites. Detection accuracy for payment redirect scripts depends on whether the malicious code is inline and matches known patterns. Always exercise your own judgement when browsing.

Google works to provide the most accurate and up-to-date information about unsafe web resources. However, Google cannot guarantee that its information is comprehensive and error-free: some risky sites may not be identified, and some safe sites may be identified in error.
